# stbenjam/homebrew-tap

Homebrew formulae for [skillsaw](https://github.com/stbenjam/skillsaw), a
linter for agent skills, plugins, and AI coding assistant context.

```bash
brew install stbenjam/tap/skillsaw
```

The `Bump skillsaw` workflow checks PyPI every six hours. On a new release it
updates the formula, builds and tests bottles for macOS (Apple silicon) and
Linux (x86_64), uploads them to a GitHub release, and commits the result to
`main`. Other platforms build from source.
